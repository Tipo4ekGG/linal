# Линал

Статический учебный справочник по линейной алгебре. Теория следует семи лекциям ВАВТ. Конспекты по квадратичным формам и комплексным числам дополняют лекции. Практика включает задачи из разборов в ChatGPT и Claude, а также дополнительные упражнения.

- `course.js` — темы, формулы, задачи, ответы и шаги.
- `app.js` — навигация, поиск, проверка ответов и локальный прогресс.
- `style.css` — оформление справочника и адаптация к телефону.

Сборка не нужна. Для локального запуска откройте `index.html` или выполните `python3 -m http.server 8080` в корне репозитория. Для GitHub Pages используйте ветку `main` и каталог `/ (root)`.
